# Lab 02A - Vending Machine

## Description

This program simulates a vending machine. Customers can view the inventory, insert coins, select an item, receive change, and cancel a transaction for a refund.

The machine tracks inventory throughout the program and does not allow customers to purchase sold-out items.

## How to Build

g++ -Wall vending.cpp -o vending

## How to Run

./vending

## Core Requirements

* Inventory with slot codes, names, prices, and quantities
* Formatted inventory display
* Nickels, dimes, quarters, and dollar coins
* Running credit display
* Selection validation
* Sold-out checking
* Insufficient-credit checking
* Change calculation
* Receipt printing
* Inventory tracking
* Transaction cancellation and refunds
* Input validation
* Main transaction loop
